# 로드맵

**목표:** 내 방을 본뜬 시뮬레이션 안에서, 자연어(키보드, 이후 음성)로 명령하면 환경을 인식하고 행동하는 **나만의 애완 오리** 만들기.
명령이 없을 때도 스스로 돌아다니고, 다가오고, 심심해하는 반응형 애완동물이 목표입니다.

## 설계 원칙

1. **LLM은 "무엇을 할지"만 정하고, "어떻게 움직일지"는 RL 정책이 맡습니다.**
   LLM은 수 초에 한 번 생각하지만, 관절은 초당 50번 제어해야 하기 때문입니다.
2. **추론할 때 시뮬레이터의 정답 좌표를 쓰지 않습니다.** 카메라와 IMU 정보만 씁니다.
   나중에 실물 로봇(sim2real)으로 옮기기 위해서입니다.
   정답 정보는 **학습 데이터를 만들 때만** 씁니다.
3. **ROS2로 모든 부품을 연결합니다.** 실물로 옮길 때는 "MuJoCo 브리지 노드"를 "실물 로봇 노드"로 바꾸기만 하면 되게 만듭니다.

## 전체 구조

```
 키보드 / 마이크 ──▶ [STT: faster-whisper] ──▶ "go push the red ball"
                                                   │
                                                   ▼
                       [두뇌: 로컬 LLM (Ollama, 8B급 도구 호출 모델)]
                        도구 목록 + 지금 보이는 물체 목록을 보고 순서를 정함
                        → walk_to("red ball") → push("red ball")
                                                   │  ROS2 Action
         ┌─────────────────────────────────────────┼──────────────────────────┐
         ▼                                         ▼                          ▼
 [행동 관리: Behavior Tree]             [기술(Skill) Action 서버]      [인식]
  명령이 없을 때 돌아다니기,             walk_to / follow / look_at     머리 카메라 RGB-D
  다가오기, 심심해하기                   sit / dance / push_ball        → YOLO 물체 탐지
  (내부 상태: 심심함, 에너지)            happy / sad + 효과음           → 물체 3D 위치
                                                   │                    → 의미 지도
                                                   ▼
                       [RL 정책 (ONNX)] 속도 + 고개 명령 → 관절 14개 (50Hz)
                                                   │
                                                   ▼
                       [MuJoCo 시뮬레이션 + 뷰어] ⇄ ROS2 브리지 노드
```

> 현재 걷기 정책은 이동 속도뿐 아니라 **고개 명령(목·머리 pitch/yaw/roll)도 입력으로 받습니다.**
> 그래서 `look_at`, 감정 표현 같은 기술은 새로 학습하지 않고도 만들 수 있습니다.

### 0단계: Ubuntu 환경 구축

- [ ] ROS2 Jazzy 실행 환경(`duck_ros`, RoboStack) 구성
- **결과물:** Ubuntu에서 오리가 키보드로 걷는 화면

### 1단계: 방 만들기 + ROS2 브리지
- [ ] 줄자로 방을 재서 기본 도형(상자, 원기둥)으로 MJCF 작성 (Blender 불필요)
- [ ] 오리 머리에 RGB-D 카메라 추가
- [ ] `duck_sim_bridge` 노드 작성
  - 발행: `/camera/image`, `/camera/depth`, `/imu`, `/joint_states`
  - 구독: `/cmd_vel`, `/head_cmd` → ONNX 정책 → 관절 제어
- [ ] ROS2 키보드 조종 노드로 조종하고, rviz2에서 카메라 화면 보기
- [ ] (병행) Blender 기초를 배워 가구를 메시로 교체. MuJoCo는 충돌용 모양(단순 도형)과 보이는 모양(메시)을 따로 둘 수 있음
- **배울 것:** ROS2 노드/토픽/메시지, MJCF, rviz2

### 2단계: 기본 기술 (ROS2 Action)
- [ ] `turn(angle)`, `walk(distance)`, `look_at(direction)`
- [ ] 감정과 춤: `wag_head()`, `happy()`, `sad()`, `dance()`. 고개 명령 + 몸 흔들기를 시간 순서로 짜 둔 키프레임 동작 + 효과음
- **배울 것:** ROS2 Action(오래 걸리는 작업을 진행 상황을 받으며 실행/취소하는 통신), 키프레임 애니메이션
- **결과물:** `happy` 액션을 호출하면 기뻐하는 동작과 소리

### 3단계: 인식 (카메라만으로 물체 찾기)
- [ ] 시뮬레이터의 정답 정보로 **라벨 붙은 학습 이미지를 자동 생성** (물체 배치/조명/색을 무작위로 바꿔서)
- [ ] YOLO 학습 → 머리 카메라 이미지에서 물체 탐지
- [ ] 탐지 상자 + 깊이 → 오리 기준 3D 위치
- [ ] 오도메트리(IMU + 다리 움직임으로 이동량 추정) + 의미 지도(본 물체 기억, 계속 갱신 → 방 배치가 바뀌어도 대응)
- **배울 것:** 객체 탐지, 합성 데이터, 도메인 랜덤화, 카메라 좌표 변환
- **결과물:** rviz2에 인식한 물체 목록과 위치가 실시간 표시

### 4단계: 언어 → 행동 (첫 번째 진짜 데모)
- [ ] Ollama + 8B급 도구 호출 모델 (4비트 양자화, GPU 약 5~6GB)
- [ ] `duck_brain` 노드: 영어 명령 + 도구 목록 + 인식된 물체 → 도구 호출 → ROS2 Action 실행
- [ ] `walk_to(object)`: 인식 결과로 방향을 잡고 속도 명령을 계속 보정하며 접근
- **배울 것:** LLM 도구 호출, 프롬프트 설계
- **결과물:** *"go to the red block and look up"* 입력 → 수행

### 5단계: 애완동물다운 자율 행동
- [ ] Behavior Tree(`py_trees`): 명령이 있으면 명령 수행, 없으면 내부 상태에 따라 행동
- [ ] 내부 상태: 심심함, 에너지, 사용자에 대한 관심
- [ ] 시뮬레이션 안에 내가 조종하는 "사람" 물체 → YOLO로 탐지 → `follow_person`, 다가오기
- [ ] LLM은 명령이 들어올 때만 호출 (GPU와 반응 속도 절약)
- **배울 것:** Behavior Tree, 상태 기계
- **결과물:** 가만히 두면 혼자 놀다가 다가오고, 오래 놔두면 심심해함

### 6단계: 새 RL 기술 (MJX + PPO, 쉬운 것부터)
- [ ] 앉기 — **현재 모델로 불가**(몸통 충돌 없음, 다리만 접으면 몸통이 2cm 만 낮아짐). 모델 변경 필요
- [~] 공 밀기 — 학습/시뮬레이션 평가 완료(정답 관측 기준 48%), ROS 인식 연동은 성공 0/10(재학습도 실패, 원인은 상태 추정. docs/PROGRESS.md 참고)
- [ ] 계단 오르기 (실물로 옮기려면 발밑 높이를 깊이 카메라로 인식해야 함). 오리 키가 약 40cm라 계단은 몇 cm 높이
- [ ] 버튼 누르기 (팔이 없으므로 머리/부리로 누름. 키프레임을 먼저 시도하고 안 되면 RL)
- **배울 것:** 보상 설계, 관측값 설계, 커리큘럼 학습
- **결과물 (최종 데모):** *"climb the stairs and press the red button"*

### 7단계: 음성 입력
- [ ] faster-whisper (small, 영어) push-to-talk
- [ ] 이후 "Hey Duck" 호출어 감지
- **결과물:** 말로 명령

### 이후: 실물 로봇 (sim2real)

- `duck_sim_bridge`를 실물 로봇 노드로 교체

### 8단계 (추가 결정, 2026-11-09): 개방형 탐지 — VLM 으로 처음 보는 물체 찾기
- **배경:** 현재 구조는 VLA 가 아니라 `LLM(글만 이해) → 도구 호출 → 기술` 파이프라인이고, 인식은 YOLO 가 아는 4종류(red_block, green_block, blue_ball, person)만 가능. LLM 은 이미지를 보지 않음
- **계획 (6단계 새 RL 기술을 끝낸 뒤):** 인식 단계에 비전-언어 모델(VLM)을 추가해 "이 이미지에서 노란 컵이 어디 있나?" 같은 질문으로 **학습하지 않은 물체도 탐지**. 나머지 구조(도구 호출, 시각 서보잉, 지도)는 그대로 유지
- [x] VLM 후보 조사/선정 — OWLv2 선택(측정표는 docs/PROGRESS.md) (RTX 3080 10GB 에서 LLM 과 함께 돌 수 있어야 함: GPU 메모리 계획 표 갱신)
- [x] 개방형 탐지 노드: 이미지 + 글 질문 → 상자/점 → 기존 깊이 파이프라인으로 3D 위치
- [x] 방에 새 물체(예: 노란 컵) 추가 후 "go to the yellow cup" 성공률 측정, YOLO 와 속도/정확도 비교
- **결과물:** 학습하지 않은 물체 이름으로 명령해도 찾아가는 데모

## GPU 메모리 계획 (RTX 3080 10GB)

| 실행 중일 때 | 사용량(대략) |
|---|---|
| LLM 8B (4비트) | 5~6 GB |
| YOLO | 약 1 GB |
| faster-whisper small | 약 1 GB |
| MuJoCo + 걷기 정책(ONNX) | CPU에서 실행 |

> **RL 학습(MJX)은 GPU를 거의 다 쓰므로** 학습할 때는 다른 것들을 끄고 따로 돌립니다.
